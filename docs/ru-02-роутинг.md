# 2. Подключение страниц к роутам

## Как работает роутинг в Symfony

Symfony сопоставляет HTTP-запрос (URL + метод) с методом контроллера. Роуты в этом проекте объявляются с помощью **PHP-атрибутов** прямо над методами контроллеров — это современный и предпочтительный подход.

## Цепочка: запрос → роут → контроллер → ответ

```
Браузер GET /deposit
    → Symfony Router читает атрибут #[Route('/deposit')]
    → Вызывается HomeController::acceptDeposit()
    → Возвращается JsonResponse / Response
    → Браузер получает ответ
```

---

## Текущие роуты проекта

Файл: `src/Controller/HomeController.php`

```php
namespace App\Controller;

use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\JsonResponse;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Attribute\Route;

class HomeController extends AbstractController
{
    #[Route('/')]
    public function home(): Response
    {
        return $this->render('base.html.twig');
    }

    #[Route('/deposit')]
    public function acceptDeposit(Request $request): Response
    {
        return new JsonResponse();
    }
}
```

| URL | Метод | Контроллер | Возвращает |
|-----|-------|-----------|-----------|
| `/` | GET | `HomeController::home()` | HTML (Twig-шаблон) |
| `/deposit` | GET/POST | `HomeController::acceptDeposit()` | JSON |

## Как добавить новый роут (пошагово)

### 1. Создать метод в контроллере

Добавьте новый метод в существующий или новый контроллер. Минимальный пример:

```php
// src/Controller/HomeController.php

#[Route('/about')]
public function about(): Response
{
    return $this->render('about.html.twig');
}
```

### 2. Ограничить HTTP-метод (опционально)

```php
#[Route('/api/user', methods: ['POST'])]
public function createUser(Request $request): JsonResponse
{
    $data = json_decode($request->getContent(), true);
    // обработка...
    return new JsonResponse(['status' => 'created'], 201);
}
```

### 3. Параметры в URL

```php
// URL вида /user/42
#[Route('/user/{id}', methods: ['GET'])]
public function showUser(int $id): Response
{
    // $id автоматически инжектится из URL
    return $this->render('user/show.html.twig', ['id' => $id]);
}
```

### 4. Именованный роут

```php
#[Route('/about', name: 'app_about')]
public function about(): Response
{
    return $this->render('about.html.twig');
}
```

Имя роута используется при генерации URL в шаблонах:

```twig
<a href="{{ path('app_about') }}">О нас</a>
```

## Как создать новый контроллер

Через консольную команду (внутри контейнера):

```bash
docker compose exec php bin/console make:controller ProductController
```

Symfony автоматически создаст:
- `src/Controller/ProductController.php` — с базовым роутом
- `templates/product/index.html.twig` — пустой шаблон

## Конфигурация роутинга

### config/routes.yaml

```yaml
controllers:
  resource: routing.controllers
```

Symfony сканирует все классы в `src/Controller/` и собирает роуты из PHP-атрибутов `#[Route(...)]`.

### config/packages/routing.yaml

```yaml
framework:
  router:
    utf8: true
  default_uri: '%env(DEFAULT_URI)%'
```

`default_uri` используется для генерации абсолютных URL в CLI-контексте (например, в командах консоли).

## Генерация URL в контроллерах

```php
// Через имя роута (предпочтительно)
$url = $this->generateUrl('app_about');

// Абсолютный URL
use Symfony\Component\Routing\Generator\UrlGeneratorInterface;
$url = $this->generateUrl('app_about', [], UrlGeneratorInterface::ABSOLUTE_URL);
```

## Передача параметров в шаблон

```php
#[Route('/products')]
public function list(): Response
{
    $products = ['Apple', 'Banana', 'Cherry'];

    return $this->render('product/list.html.twig', [
        'products' => $products,
    ]);
}
```

В шаблоне `templates/product/list.html.twig`:

```twig
{% for product in products %}
    <li>{{ product }}</li>
{% endfor %}
```

## Роуты для API (JSON-ответы)

```php
#[Route('/api/deposit', methods: ['POST'])]
public function createDeposit(Request $request): JsonResponse
{
    $data = json_decode($request->getContent(), true);
    $amount = $data['amount'] ?? 0;

    // бизнес-логика...

    return $this->json([
        'success' => true,
        'amount'  => $amount,
    ]);
}
```

`$this->json()` — короткий способ вернуть `JsonResponse` с правильными заголовками.
