# 3. Формирование страниц

Страница в этом проекте состоит из трёх уровней:

1. **Контроллер** — обрабатывает запрос и передаёт данные в шаблон
2. **Twig-шаблон** — HTML-структура страницы
3. **React-компонент** — интерактивная часть интерфейса (опционально)

---

## Уровень 1 — Контроллер

Контроллер принимает запрос и рендерит шаблон. Данные передаются вторым аргументом `render()`.

```php
// src/Controller/HomeController.php

#[Route('/')]
public function home(): Response
{
    return $this->render('base.html.twig');
}
```

Передача данных в шаблон:

```php
#[Route('/products')]
public function productList(): Response
{
    return $this->render('product/list.html.twig', [
        'title'    => 'Список товаров',
        'products' => ['Apple', 'Banana'],
    ]);
}
```

## Уровень 2 — Twig-шаблон

### Текущий базовый шаблон (templates/base.html.twig)

```twig
<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="UTF-8">
        <title>{% block title %}Welcome!{% endblock %}</title>
        {% block stylesheets %}
            {{ encore_entry_link_tags('app') }}
        {% endblock %}
        {% block javascripts %}
            {{ encore_entry_script_tags('app') }}
        {% endblock %}
    </head>
    <body>
        {% block body %}
            <div class="container-fluid px-4">
                <h1 class="mt-4">Deposits</h1>
                <div {{ react_component('DepositForm') }}></div>
            </div>
        {% endblock %}
    </body>
</html>
```

Ключевые элементы:

| Элемент | Назначение |
|---------|-----------|
| `{% block title %}` | Блок для переопределения заголовка страницы |
| `{{ encore_entry_link_tags('app') }}` | Подключает скомпилированный CSS из Webpack |
| `{{ encore_entry_script_tags('app') }}` | Подключает скомпилированный JS из Webpack |
| `{% block body %}` | Блок для содержимого страницы |
| `{{ react_component('DepositForm') }}` | Монтирует React-компонент в страницу |

### Создание нового шаблона

Создайте файл `templates/about.html.twig`:

```twig
{% extends 'base.html.twig' %}

{% block title %}О нас{% endblock %}

{% block body %}
    <div class="container mt-4">
        <h1>О проекте</h1>
        <p>{{ description }}</p>
    </div>
{% endblock %}
```

> Если используете `{% extends %}` — базовый шаблон должен содержать все блоки, которые вы переопределяете.

В текущем проекте `base.html.twig` является и базовым шаблоном, и единственной страницей одновременно. При расширении проекта рекомендуется вынести HTML-каркас в отдельный `layout.html.twig`.

## Уровень 3 — React-компонент

### Как подключить компонент к шаблону

В Twig-шаблоне:

```twig
<div {{ react_component('DepositForm') }}></div>
```

Symfony UX React автоматически находит компонент по имени в папке `assets/react/controllers/`.

Передача пропсов из Twig в React:

```twig
<div {{ react_component('DepositForm', { 'initialAmount': 500, 'currency': 'RUB' }) }}></div>
```

### Текущий React-компонент (assets/react/controllers/DepositForm.tsx)

```tsx
import { useState, useEffect } from 'react';
import { ApiService } from '../services/ApiService';

interface FormData {
    amount: number;
}

export default function DepositForm() {
    const [formData, setFormData] = useState<FormData>({ amount: 0 });
    const [depositSuccess, setDepositSuccess] = useState<boolean>(false);
    const apiService = new ApiService();

    useEffect(() => {
        if (depositSuccess) {
            console.log('Form submitted successfully!');
        }
    }, [depositSuccess]);

    const handleChange = (event: any) => {
        const { name, value } = event.target;
        setFormData(prev => ({ ...prev, [name]: value }));
    };

    const handleForm = () => {
        apiService.sendDeposit(formData.amount).then(r => {
            if (!r.ok) throw new Error(`HTTP error! Status: ${r.status}`);
            setDepositSuccess(true);
        });
    };

    return (
        <div>
            <input type="text" name="amount" value={formData.amount} onChange={handleChange} />
            <button onClick={handleForm}>Send deposit</button>
        </div>
    );
}
```

### Создание нового React-компонента (пошагово)

#### Шаг 1 — Создать файл компонента

```tsx
// assets/react/controllers/UserProfile.tsx
import { useState } from 'react';

interface Props {
    userId: number;
    userName?: string;
}

export default function UserProfile({ userId, userName = 'Гость' }: Props) {
    const [isEditing, setIsEditing] = useState(false);

    return (
        <div className="card">
            <div className="card-body">
                <h5>Пользователь #{userId}</h5>
                <p>{userName}</p>
                <button
                    className="btn btn-primary"
                    onClick={() => setIsEditing(!isEditing)}
                >
                    {isEditing ? 'Сохранить' : 'Редактировать'}
                </button>
            </div>
        </div>
    );
}
```

> **Важно:** файл должен лежать в `assets/react/controllers/` и экспортировать компонент через `export default`.

#### Шаг 2 — Подключить в Twig-шаблоне

```twig
<div {{ react_component('UserProfile', { 'userId': 42, 'userName': 'Иван' }) }}></div>
```

#### Шаг 3 — Пересобрать ресурсы

```bash
# Разовая сборка
npm run dev

# Или следить за изменениями
npm run watch
```

После этого компонент появится на странице.

## Как работает регистрация React-компонентов

Файл `assets/app.ts`:

```typescript
import { registerReactControllerComponents } from '@symfony/ux-react';
registerReactControllerComponents(require.context('./react/controllers', true, /\.([jt])sx?$/));
```

Webpack автоматически находит все `.tsx`, `.ts`, `.jsx`, `.js` файлы в `assets/react/controllers/` и регистрирует их как компоненты. Имя компонента в `react_component()` совпадает с именем файла (без расширения).

| Файл | Имя в react_component() |
|------|------------------------|
| `assets/react/controllers/DepositForm.tsx` | `'DepositForm'` |
| `assets/react/controllers/UserProfile.tsx` | `'UserProfile'` |
| `assets/react/controllers/admin/Dashboard.tsx` | `'admin/Dashboard'` |

## HTTP-запросы из React в Symfony

Готовый сервис: `assets/react/services/ApiService.ts`

```typescript
export class ApiService {
    sendDeposit(amount: number): Promise<Response> {
        return fetch('/deposit', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ amount }),
        });
    }
}
```

Использование в компоненте:

```tsx
const apiService = new ApiService();
apiService.sendDeposit(500).then(response => {
    if (response.ok) {
        // успех
    }
});
```

Добавление нового метода в ApiService:

```typescript
async getProducts(): Promise<Product[]> {
    const response = await fetch('/api/products');
    return response.json();
}
```

## Полный пример: новая страница с React-компонентом

### 1. Контроллер

```php
// src/Controller/HomeController.php
#[Route('/users')]
public function users(): Response
{
    return $this->render('users.html.twig', [
        'pageTitle' => 'Пользователи',
    ]);
}
```

### 2. Шаблон (templates/users.html.twig)

```twig
{% extends 'base.html.twig' %}

{% block title %}{{ pageTitle }}{% endblock %}

{% block body %}
    <div class="container mt-4">
        <h1>{{ pageTitle }}</h1>
        <div {{ react_component('UserList') }}></div>
    </div>
{% endblock %}
```

### 3. Компонент (assets/react/controllers/UserList.tsx)

```tsx
import { useState, useEffect } from 'react';

export default function UserList() {
    const [users, setUsers] = useState<string[]>([]);

    useEffect(() => {
        fetch('/api/users')
            .then(r => r.json())
            .then(data => setUsers(data));
    }, []);

    return (
        <ul>
            {users.map((user, i) => <li key={i}>{user}</li>)}
        </ul>
    );
}
```

### 4. Сборка

```bash
npm run dev
```

### 5. Открыть страницу

```
https://localhost/users
```

## Глобальные стили

Файл `assets/styles/app.css` подключается через `app.ts` и применяется ко всем страницам.
Дополнительные стили конкретной страницы можно добавить прямо в шаблон:

```twig
{% block stylesheets %}
    {{ parent() }}
    <style>
        .my-custom-class { color: red; }
    </style>
{% endblock %}
```
