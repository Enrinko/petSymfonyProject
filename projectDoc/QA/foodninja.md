# Тест-кейсы — Short Links (репо FoodNinja)

← Назад к индексу: [[README]]

## Описание

Карточка **«Short Links»** в «Оркестр → Проекты» ведёт на внешний проект
(репозиторий называется **FoodNinja**) — сервис коротких ссылок на **Laravel 11**
с админ-кабинетом на **Filament v3** (`/admin`). Базовый сценарий: регистрация /
вход → создание короткой ссылки (автокод base62, 6 символов) → переход по
`GET /{code}` отдаёт 302-редирект на оригинал и фиксирует клик (IP, время, UA,
Referer) → статистика по ссылке и виджет дашборда. Ссылки изолированы по
пользователям; неизвестный код → 404.

## Предусловия / окружение

> Сначала выполнить **общие предусловия** из [[README]] (поднять стек,
> `sh bin/projects up`, `docker compose restart php`, доверие сертификату).

| Параметр | Значение |
| --- | --- |
| URL приложения | `https://foodninja.localhost` |
| Админ-кабинет | `/admin` (Filament) |
| Порт сабмодуля | `APP_PORT=8081` |
| Порт БД (форвард) | `FORWARD_DB_PORT=5433` |
| Прочее окружение | `APP_KEY`, `WWWUSER` / `WWWGROUP` |
| Демо-пользователь | `demo@example.com` / `password` |
| Маршрут редиректа | `GET /{shortCode}` (ограничение кода — 6 символов base62) |

> [!warning] Сверка значений
> Маршрут редиректа и ограничение `[A-Za-z0-9]{6}`, политику изоляции и
> демо-пользователя сверять с исходниками сабмодуля при локальном прогоне:
> `projects/foodninja/routes/web.php`, `LinkPolicy`, сидеры и README сабмодуля.

## A. Доступ через Оркестр

### FN-A01 · Карточка «Short Links» на `/projects`
- **Приоритет:** Высокий
- **Предусловия:** стек и проекты подняты.
- **Шаги:**
  1. Открыть `https://localhost/projects`.
  2. Найти карточку «Short Links».
- **Ожидаемый результат:** карточка показывает название «Short Links», описание,
  стек «Laravel 11 · Filament», иконку 🔗 и ссылку; данные совпадают с
  `config/projects.yaml`. (Примечание: репозиторий называется FoodNinja —
  расхождение имени ожидаемо.)

### FN-A02 · Переход по карточке открывает кабинет
- **Приоритет:** Высокий
- **Предусловия:** FN-A01 пройден.
- **Шаги:**
  1. Кликнуть по карточке.
- **Ожидаемый результат:** открывается `https://foodninja.localhost`, происходит
  редирект на `/admin` (форма логина Filament).

### FN-A03 · (нег.) Приложение не поднято → диагностика
- **Приоритет:** Средний
- **Предусловия:** контейнер FoodNinja остановлен.
- **Шаги:**
  1. Перейти на `https://foodninja.localhost`.
- **Ожидаемый результат:** Caddy отдаёт **502** (или иную явную ошибку прокси);
  диагностика по `docs/ru-проекты.md`.

## B. Функциональность приложения

### FN-01 · Регистрация нового пользователя
- **Приоритет:** Средний
- **Предусловия:** открыт `/admin/register`.
- **Шаги:**
  1. Заполнить форму регистрации валидными данными.
  2. Отправить.
- **Ожидаемый результат:** пользователь создан и авторизован, открыт дашборд
  `/admin`.

### FN-02 · Вход демо-пользователем
- **Приоритет:** Высокий
- **Предусловия:** открыт `/admin/login`; `demo@example.com` сидирован.
- **Шаги:**
  1. Ввести `demo@example.com` / `password`.
  2. Нажать «Войти».
- **Ожидаемый результат:** вход успешен, открыт дашборд `/admin`.

### FN-03 · Неуспешный вход
- **Приоритет:** Высокий
- **Предусловия:** `/admin/login`.
- **Шаги:**
  1. Ввести неверные email/пароль.
  2. Отправить.
- **Ожидаемый результат:** показана ошибка авторизации; вход не выполнен.

### FN-04 · Доступ к `/admin` без авторизации
- **Приоритет:** Высокий
- **Предусловия:** нет активной сессии.
- **Шаги:**
  1. Открыть `/admin` напрямую.
- **Ожидаемый результат:** редирект на `/admin/login`.

### FN-05 · Выход из кабинета
- **Приоритет:** Средний
- **Предусловия:** пользователь авторизован.
- **Шаги:**
  1. Выполнить выход из аккаунта в Filament.
- **Ожидаемый результат:** сессия завершена, редирект на `/admin/login`.

### FN-06 · Создание короткой ссылки
- **Приоритет:** Высокий
- **Предусловия:** пользователь авторизован.
- **Шаги:**
  1. Перейти в раздел Links → «New link».
  2. Указать Original URL (валидный) и сохранить.
- **Ожидаемый результат:** ссылка создана; автоматически сгенерирован код из
  6 символов base62 (`[A-Za-z0-9]`); короткий URL вида
  `https://foodninja.localhost/{code}`.

### FN-07 · Список своих ссылок
- **Приоритет:** Средний
- **Предусловия:** есть хотя бы одна созданная ссылка.
- **Шаги:**
  1. Открыть список ссылок.
- **Ожидаемый результат:** видны короткий URL, кнопка копирования и счётчик
  кликов для каждой ссылки текущего пользователя.

### FN-08 · Редирект `GET /{code}`
- **Приоритет:** Высокий
- **Предусловия:** есть ссылка с кодом `{code}`.
- **Шаги:**
  1. Открыть `https://foodninja.localhost/{code}` (в браузере или `curl -I`).
- **Ожидаемый результат:** ответ **302** с `Location` на оригинальный URL;
  переход ведёт на исходный адрес.

### FN-09 · Фиксация клика
- **Приоритет:** Высокий
- **Предусловия:** есть ссылка; известен текущий счётчик кликов.
- **Шаги:**
  1. Выполнить переход по короткой ссылке (можно с заголовком Referer).
  2. Открыть детали ссылки / список кликов.
- **Ожидаемый результат:** создаётся запись клика с IP, датой/временем,
  User-Agent и Referer; счётчик кликов увеличивается на 1.

### FN-10 · Статистика по ссылке
- **Приоритет:** Средний
- **Предусловия:** по ссылке есть ≥1 клик.
- **Шаги:**
  1. Открыть просмотр (View) ссылки.
- **Ожидаемый результат:** показан список переходов и общее число кликов;
  значения соответствуют реально выполненным переходам.

### FN-11 · Удаление ссылки (каскад кликов)
- **Приоритет:** Средний
- **Предусловия:** есть ссылка с зафиксированными кликами.
- **Шаги:**
  1. Удалить ссылку.
  2. Проверить связанные записи кликов.
- **Ожидаемый результат:** ссылка удалена; связанные клики удаляются каскадно;
  `GET /{code}` для удалённого кода → 404.

### FN-12 · Виджет дашборда
- **Приоритет:** Низкий
- **Предусловия:** у пользователя есть ссылки и клики.
- **Шаги:**
  1. Открыть дашборд `/admin`.
- **Ожидаемый результат:** виджет показывает корректные суммы «Моих ссылок» и
  «Всего кликов» для текущего пользователя.

## C. Негативные и граничные случаи

### FN-13 · Неизвестный код и код иной длины
- **Приоритет:** Высокий
- **Предусловия:** —
- **Шаги:**
  1. Открыть `/{случайный-6-символьный-код}`, которого нет в БД.
  2. Открыть код иной длины (например, 5 или 7 символов).
- **Ожидаемый результат:** неизвестный 6-символьный код → **404**; код иной
  длины не матчит маршрут (ограничение `[A-Za-z0-9]{6}`) → 404/не обрабатывается
  как short-link.

### FN-14 · Уникальность кода
- **Приоритет:** Средний
- **Предусловия:** пользователь авторизован.
- **Шаги:**
  1. Создать несколько ссылок подряд.
  2. Сверить сгенерированные коды.
- **Ожидаемый результат:** все коды уникальны, повторов нет.

### FN-15 · Изоляция пользователей
- **Приоритет:** Высокий
- **Предусловия:** два пользователя (A и B), у каждого свои ссылки.
- **Шаги:**
  1. Под пользователем A открыть список ссылок.
  2. Под A попытаться открыть View ссылки пользователя B по прямому URL.
- **Ожидаемый результат:** A видит только свои ссылки; прямой доступ к чужой
  ссылке запрещён (403/404) согласно `LinkPolicy`.

### FN-16 · Валидация Original URL
- **Приоритет:** Средний
- **Предусловия:** форма создания ссылки.
- **Шаги:**
  1. Сохранить с пустым Original URL.
  2. Сохранить со значением, не являющимся URL.
- **Ожидаемый результат:** в обоих случаях показана ошибка валидации; ссылка не
  создаётся.

### FN-17 · Накопление кликов
- **Приоритет:** Низкий
- **Предусловия:** есть ссылка с известным счётчиком.
- **Шаги:**
  1. Выполнить переход по короткой ссылке несколько раз подряд.
- **Ожидаемый результат:** каждый переход инкрементит счётчик и создаёт отдельную
  запись клика; итог соответствует числу переходов.
